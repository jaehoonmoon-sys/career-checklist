# 그로스 마케터 JD 분석

> 출처: 원티드·링크드인 채용공고 패턴 분석 (크림/KREAM, 스노우, 29CM, 코멘토, 허들러스, 모두닥 등) + 코드스테이츠 그로스 마케터 취업 분석 + 팀스파르타 디마5기 튜터 교안 (배지은 튜터, 2026.04.23)

---

## 직무 정의

**"데이터를 기반으로 서비스 전체 성장을 책임지는 실험자"**

핵심 미션: AARRR 퍼널 전체를 관장하며 서비스 성장 병목을 해소하고, 가설 → 실험 → 개선 사이클을 반복

---

## 퍼포먼스 마케터와의 차이

| 구분 | 퍼포먼스 마케팅 | 그로스 마케팅 |
|------|----------------|---------------|
| 목표 | 광고 효율 개선 | 서비스 전체 성장 |
| 범위 | 광고 채널 중심 | 전체 고객 퍼널 |
| 주요 지표 | ROAS, CPA | 활성화·리텐션·LTV |
| 관여 영역 | 마케팅 | 마케팅 + 제품 + UX |

---

## AARRR 프레임워크

| 단계 | 의미 | 핵심 지표 |
|------|------|-----------|
| Acquisition (획득) | 신규 사용자 유입 | CAC, 채널별 유입수 |
| Activation (활성화) | 첫 핵심 행동 완료 | 온보딩 완료율, 첫 구매율 |
| Retention (유지) | 재방문·재구매 | DAU/MAU, 리텐션율 |
| Referral (추천) | 자발적 바이럴 | NPS, 초대 전환율 |
| Revenue (수익) | 매출 창출 | LTV, ARPU |

---

## 주요 업무

- AARRR 프레임워크 기반 성장 병목 구간 분석
- 가설 수립 → A/B 테스트 설계 → 결과 분석 반복 (그로스 사이클)
- 온보딩 플로우·랜딩 페이지 전환율 개선 실험
- 퍼포먼스(유입)와 CRM(리텐션) 통합 운영
- 성장 지표 대시보드 구축 및 주기적 리포팅
- 신규 채널 발굴 및 바이럴·레퍼럴 구조 설계
- 데이터 분석 도구를 활용한 서비스 지표 분석 및 전략 제언
- 제품팀·데이터팀·UX팀과 긴밀한 협업

## 핵심 역량 (필수)

| 역량 | 설명 |
|------|------|
| AARRR 퍼널 이해 | 고객 여정 단계별 지표 설정과 분석 |
| 가설 검증 | 데이터 기반 가설 수립 및 실험 설계 |
| A/B 테스트 | 통계적 유의성을 고려한 실험 설계와 해석 |
| 리텐션 설계 | 재방문·재구매 유도 구조 기획 |
| 데이터 기반 의사결정 | 지표 해석 후 성장 우선순위 도출 능력 |
| 제품·마케팅 협업 | 개발·기획·디자인팀과의 협업 경험 |
| 풀퍼널 이해 | 유입부터 수익까지 전 단계 마케팅 이해 |

---

## 우대 역량 / 경험

- SQL을 활용한 직접 데이터 추출 경험
- Amplitude·Mixpanel 등 행동 분석 툴 사용 경험
- 실제 A/B 테스트 기획·운영·해석 경험
- CAC, LTV 등 비즈니스 지표 분석 경험
- Python / R 데이터 분석 기초
- CRM 툴(Braze, Airbridge) 연계 경험
- 앱·플랫폼 서비스 도메인 경험 (스타트업 선호)
- 5년 이상 관련 경력 (크림, 스노우 등 대형 플랫폼 기준)

---

## 주요 활용 툴

| 툴 | 용도 |
|----|------|
| Amplitude / Mixpanel | 사용자 행동 흐름·퍼널 분석 |
| GA4 | 웹 유입·전환 추적 |
| Braze / Airbridge | CRM 자동화·리텐션 캠페인 |
| Optimizely / AB Tasty | A/B 테스트 실험 설계 |
| Looker Studio | 성장 지표 대시보드 |
| SQL | 직접 데이터 추출 및 분석 |

---

## 직무 특성 (면담 참고)

- 신입 평균 연봉 약 2,800만 원, 3년차부터 일반 마케터 대비 높아짐
- 대부분 스타트업·테크 컴퍼니에서 채용 (대기업보다 플랫폼 중심)
- 데이터 분석 능력이 타 직무보다 훨씬 중요
- 마케팅만이 아닌 제품·UX까지 이해가 필요한 T자형 인재 선호

# Career Checklist — 프로젝트 기획서

> 디지털 마케터 부트캠프 수강생 진로 탐색 및 면담 준비 지원 도구  
> 작성일: 2026-06-09 | 담당 PM: 문재훈 (팀스파르타)

---

## 1. 목적 및 배경

### 왜 만드는가
디마 부트캠프 수강생들이 진로 고민을 할 때 "어떤 마케터가 되고 싶은지", "무엇을 준비해야 하는지" 감을 잡지 못하고 있음. 튜터와의 면담에서도 수강생이 자신의 경험과 강점을 체계적으로 정리하지 못한 채 참여하는 경우가 많음.

### 이 툴로 해결하고자 하는 것
1. 마케터 4개 세부 직무(콘텐츠·브랜드·그로스·퍼포먼스)의 역량 체크를 통해 본인의 강점 방향 인식
2. 이력서·포트폴리오·JD 분석 등 취업 준비 현황을 사전에 정리
3. 면담 전 작성 → 튜터가 면담 시 해당 내용을 기반으로 구체적인 피드백 제공
4. 면담 회차별(1차·2차·3차) 진행 현황 추적 및 준비 가이드 제공

## 2. 주요 기능 정의

### 2-1. 직무 강점 진단 (설문형)
- 6개 직무별 핵심 역량 체크리스트
  - 퍼포먼스 마케터, 콘텐츠 마케터, 브랜드 마케터, 그로스 마케터, CRM 마케터, AE(광고대행사)
- 각 항목: "해당 역량에 관심이 있다 / 공부해봤다 / 실제로 해봤다" 3단계 선택
- 결과: 어떤 직무에 강점/관심이 쏠려 있는지 시각화 (레이더 차트 또는 점수 카드)
- 참고 데이터: `/jd-analysis/` 폴더 내 직무별 JD 분석

### 2-2. 공통 경험 체크리스트
수강생의 전반적인 취업 준비 현황을 파악하기 위한 공통 항목:

| 항목 | 형식 |
|------|------|
| 이력서 작성 경험 여부 | 체크 + 간단 서술 |
| 포트폴리오 제작 경험 여부 | 체크 + 링크/파일명 |
| 자기소개서 작성 경험 여부 | 체크 + 간단 서술 |
| JD 분석 경험 여부 | 체크 + 분석한 회사/직무 |
| 관련 직무 일 경험 여부 | 체크 + 간단 서술 |
| 유관 경험 여부 (대외활동·공모전 등) | 체크 + 간단 서술 |
| 아르바이트 등 사회 경험 여부 | 체크 + 간단 서술 |

### 2-3. 수강생별 기록 관리
- 수강생 이름으로 로그인(또는 이름+기수 선택)
- 과거 작성 이력 조회 및 수정 가능
- 면담 회차별 작성 기록 구분 저장

### 2-4. 면담 회차별 진행 관리
| 회차 | 목적 | 주요 체크 포인트 |
|------|------|-----------------|
| 1차 면담 | 현재 상태 파악 + 방향 설정 | 직무 강점 진단 결과, 기본 경험 현황, 관심 직무 |
| 2차 면담 | 준비 현황 점검 + 피드백 | 이력서/포트폴리오 초안, JD 분석 결과, 구체적 목표 |
| 3차 면담 | 최종 점검 + 보완 | 완성된 포트폴리오, 모의 면접 피드백, 지원 전략 |

## 4. 데이터 모델 (초안)

### students (수강생)
```
id, name, cohort(기수), created_at
```

### checklist_responses (체크리스트 응답)
```
id, student_id, session(1차/2차/3차), 
competency_scores(JSON - 직무별 역량 점수),
common_experiences(JSON - 공통 경험 체크 결과),
notes(메모),
created_at, updated_at
```

### competency_items (역량 문항)
```
id, job_type(콘텐츠/브랜드/그로스/퍼포먼스),
item_text, category(필수/우대),
weight(가중치)
```

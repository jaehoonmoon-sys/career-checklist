## 평가 방식

각 문항에 대해 아래 3단계 중 하나를 선택:

| 선택지 | 의미 | 점수 |
|--------|------|------|
| 선택 안 함 | 관심 없거나 잘 모름 | 0점 |
| 관심있다 | 이 일에 관심이 있고 배우고 싶다 | 1점 |
| 공부해봤다 | 개념을 공부하거나 영상·글로 학습했다 | 2점 |
| 해봤다 | 실제로 직접 해본 경험이 있다 (과제·인턴·프리랜서 포함) | 3점 |

**직무별 최고 점수**: 5문항 × 3점 = **15점**  
**레이더 차트**: 6개 직무 점수를 시각화 → 점수가 높은 직무 = 강점 방향

## PM 01. 퍼포먼스 마케터 (performance)

> 광고 플랫폼을 통해 신규 고객을 효율적으로 유입시키는 직무  
> 핵심 툴: Meta Ads, Google Ads, 네이버 검색광고, GA4

| ID | 문항 | 카테고리 |
|----|------|----------|
| PM-01 | Meta·Google·네이버 등 광고 플랫폼에서 직접 캠페인을 설정하고 집행하는 것 | 필수 |
| PM-02 | ROAS·CPA·CTR 등 광고 성과 지표를 분석해 개선 방향을 도출하는 것 | 필수 |
| PM-03 | 타겟 오디언스를 세분화하고 리타겟팅 전략을 설계하는 것 | 필수 |
| PM-04 | GA4·픽셀 등 트래킹 툴로 전환 경로를 추적·설정하는 것 | 필수 |
| PM-05 | 광고 소재(이미지·영상·카피)를 A/B 테스트로 비교하고 최적화하는 것 | 필수 |

**면담 활용 핵심 키워드**: ROAS, CPA, 리타겟팅, 광고 소재 테스트, 예산 최적화

## CT 02. 콘텐츠 마케터 (content)

> 채널별 콘텐츠를 기획·제작하고 성과를 분석해 브랜드 팬덤을 만드는 직무  
> 핵심 툴: Instagram·YouTube·블로그, Canva·CapCut, 인스타 인사이트

| ID | 문항 | 카테고리 |
|----|------|----------|
| CT-01 | 인스타그램·유튜브·블로그 등 SNS 채널별 콘텐츠를 기획하고 제작하는 것 | 필수 |
| CT-02 | 브랜드 톤앤매너에 맞는 카피라이팅을 작성하는 것 | 필수 |
| CT-03 | 콘텐츠 조회수·저장수·인게이지먼트를 분석하고 다음 콘텐츠에 반영하는 것 | 필수 |
| CT-04 | 뉴스레터·블로그 등 장문 텍스트 콘텐츠를 기획하고 발행하는 것 | 필수 |
| CT-05 | 트렌드와 소비자 반응을 모니터링해 콘텐츠 아이디어를 지속적으로 발굴하는 것 | 필수 |

**면담 활용 핵심 키워드**: 채널 운영 경험, 콘텐츠 성과, 카피라이팅, 트렌드 감각

> 핵심 툴: PowerPoint·Keynote, Figma (시안 리뷰), 소비자 조사 툴  
> ⚠️ **튜터 검수 필요**: 디마5기 교안에 별도 직무로 구분되지 않아 문항 내용 확인 필요

| ID | 문항 | 카테고리 |
|----|------|----------|
| BR-01 | 특정 브랜드의 포지셔닝과 차별점을 분석해 전략적으로 정리하는 것 | 필수 |
| BR-02 | 캠페인 기획서 또는 브랜드 전략서를 직접 작성하는 것 | 필수 |
| BR-03 | 브랜드 보이스(톤앤매너)를 정의하고 채널 전반에 일관되게 적용하는 것 | 필수 |
| BR-04 | 경쟁 브랜드를 분석해 시장 내 포지셔닝 전략을 도출하는 것 | 필수 |
| BR-05 | 소비자 인식 조사(설문·인터뷰)를 기획하고 인사이트를 도출하는 것 | 필수 |

**면담 활용 핵심 키워드**: 브랜드 분석 경험, 기획서 작성, 포지셔닝, 소비자 인사이트

## GR 04. 그로스 마케터 (growth)

> AARRR 퍼널 전체를 관장하며 데이터 기반으로 서비스 성장을 설계하는 직무  
> 핵심 툴: Amplitude·GA4, SQL, Braze, A/B 테스트 툴

| ID | 문항 | 카테고리 |
|----|------|----------|
| GR-01 | AARRR 퍼널(획득→활성화→유지→추천→수익) 단계별 지표를 분석하고 병목을 찾는 것 | 필수 |
| GR-02 | 데이터 기반 가설을 세우고 A/B 테스트를 설계·분석하는 것 | 필수 |
| GR-03 | SQL이나 Amplitude·GA4 등 분석 툴로 직접 데이터를 추출하고 해석하는 것 | 필수 |
| GR-04 | 재방문·재구매를 높이기 위한 리텐션 캠페인이나 온보딩 플로우를 기획하는 것 | 필수 |
| GR-05 | 제품팀·개발팀·UX팀과 협업해 서비스 전환율 개선 실험을 진행하는 것 | 필수 |

**면담 활용 핵심 키워드**: AARRR, 데이터 분석, 가설 검증, A/B 테스트, 제품 협업

## CR 05. CRM 마케터 (crm)

> 기존 고객 데이터를 활용해 재구매와 충성 고객을 설계하는 직무  
> 핵심 툴: Braze·Stibee·Mailchimp, Amplitude·GA4, SQL

| ID | 문항 | 카테고리 |
|----|------|----------|
| CR-01 | 고객을 구매 빈도·금액·최근성(RFM) 기준으로 세그먼트로 분류하는 것 | 필수 |
| CR-02 | 앱 푸시·카카오 알림톡·이메일 등 채널별 맞춤 메시지를 기획하고 발송하는 것 | 필수 |
| CR-03 | 오픈율·클릭률·재구매율 등 CRM 지표를 분석하고 메시지를 최적화하는 것 | 필수 |
| CR-04 | 고객 여정(가입→첫 구매→재구매→VIP)에 따른 자동화 메시지 시나리오를 설계하는 것 | 필수 |
| CR-05 | LTV(고객 생애가치)를 높이기 위한 이탈 방지·리텐션 캠페인 전략을 수립하는 것 | 필수 |

**면담 활용 핵심 키워드**: RFM, 고객 세그먼트, LTV, 자동화 메시지, 리텐션

> 핵심 툴: PowerPoint·Keynote, Looker Studio·GA4, Notion·Asana

| ID | 문항 | 카테고리 |
|----|------|----------|
| AE-01 | 클라이언트의 비즈니스 문제를 파악하고 마케팅 제안서(기획서)를 직접 작성하는 것 | 필수 |
| AE-02 | 논리적이고 설득력 있는 프레젠테이션을 제작하고 발표하는 것 | 필수 |
| AE-03 | 여러 프로젝트를 동시에 관리하며 일정·예산·품질을 조율하는 것 | 필수 |
| AE-04 | 클라이언트와 내부 팀 사이에서 소통 창구 역할을 하며 피드백을 반영하는 것 | 필수 |
| AE-05 | 광고 매체(Meta·Google·네이버·OOH 등)의 특성을 이해하고 예산을 배분하는 것 | 필수 |

**면담 활용 핵심 키워드**: 제안서 기획, 프레젠테이션, 멀티태스킹, 클라이언트 소통, 매체 이해
